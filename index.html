01

体检先行

动手前就知道能不能搬：五类风险（外部依赖、目录层级、保留词、许可证、工具名）逐项给等级与处置动作，结论强制三选一。

02

合规是门禁，不是提示词

许可两道具门——「能否搬运」与「能否上架」分开判定；去毒审计 35 条规则扫 6 类风险，硬问题非零退出、阻断交付。

03

中文化拆成四道工序

通读拆解、术语落定、逐段翻译、合成自检——中间产物全是可检查的文件，重做任何一道都不牵连其余。

04

官方校验器说了算

自检与平台门禁分开设：交付前必跑平台官方校验器，逐项对账，不拿「我检过了」顶数。

02 / 四种用法

同一个引擎，四种进场方式

搬一个、批量搬、接榜单、拆了重组——都不用改工具，换个说法就行。

自然语言入口

一句话说清需求：搬哪个仓库、要不要中文。引擎自动体检、转换、出包。

终端工作台

另一套流程产出的候选榜单直接接进来：自动分类 A 可搬 / B 需创作 / C 不可搬，产出可喂批量的 manifest。

03.5 / BEFORE · AFTER

一个真实技能的中文化全过程：video-transcribe

案例来自 wendy7756/AI-Video-Transcriber 内置技能（Apache-2.0，87 行中量文档，MCP＋技能双形态）。口径偏差如实报：指令单原写「从 P1 挑 MIT 小技能」，但 P1（yt-short-clipper）为 Tauri 应用无 SKILL.md，四道工序不适用——按「许可宽松 × 文档量中 × 有技能形态」的意图改选 P2 内置技能。

BEFORE · 源仓库原文

案例：video-transcribe · 87 行英文 SKILL.md

片段 A（术语：transcribe=转录 · subtitles=字幕 · fallback=降级） 原文：Runs this repo's pipeline headlessly: platform subtitles when available (seconds), local Whisper as fallback, then optimize -> translate -> summarize. 译文：以无界面方式运行本仓库的转录流水线：有平台字幕时直接取用（秒级），无字幕则降级用本地 Whisper，再依次做优化 → 翻译 → 摘要。

片段 B（同一词根两义译名分离：transcribe=转录 / transcript=转录文本） 原文：When "no_speech": true the source contains no speech. There is no transcript, summary, or translation. The pipeline deliberately skips the LLM so that nothing gets invented. 译文：当 "no_speech": true 时，源里没有语音——没有转录文本、没有摘要、没有翻译。流水线会刻意跳过 LLM，保证不编造任何内容。

术语表节选 · glossary 为唯一标准

transcribe → 转录（新词：先例检索 0 命中后新造）· transcript → 转录文本（区别于动作「转录」）· summary → 摘要（已交付 4 包先例）· fallback → 降级（26 包通行）· Whisper / ffmpeg / JSON 键 → 原样不硬译。规则：专有概念首次出现并置「中文（English）」；正文无中英夹杂整句；代码块 4 个全部原样保留。

AFTER · 交付包与验收报告

出门时：三道门禁全绿 · 白名单干净的交付包

搬运期官方校验器：通过 11 / 警告 0 / 失败 0 中文化后官方校验器复跑：通过 11 / 警告 0 / 失败 0 · 结论：通过 本地化检查：SKILL.md 覆盖率 7/7 行 = 100%（下限 90%）· 悬空引用 0 / 未引用文件 0 · PASS 交付包断言：video-transcribe-zh.zip root 直铺，一级条目 = LICENSE / SKILL.md / THIRD-PARTY-NOTICES.md / assets（4 文件，无内部文档混入）

门禁不是走过场：首轮本地化检查 FAIL，抓到悬空引用 ./install.sh（源仓库根脚本不在包内）——改措辞为「仓库根目录的安装脚本」后复跑归零。

交付前自检如实列出 REVIEW：去毒审计·供应链——未锁定版本的依赖安装（SKILL.md:33）需人工确认。抓到问题如实列而不是删掉——「带验收报告」卖的就是这个。

改动清单（porting-changes）：搬运期——7 个缺失 frontmatter 字段按映射表补全、license 自动识别 Apache-2.0、assets/LICENSE 归位；中文化期——骨架段按源重写 4 段、悬空引用 1→0、新术语回填 3 条。

残留风险（如实列，未替上游做决定）：依赖安装未锁定版本号 · 运行依赖外部仓库环境（venv / ffmpeg）。
