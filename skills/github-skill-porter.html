能解决什么问题

  • 看中 GitHub 上的 Agent 技能，但格式不兼容、目录层级不对、缺字段，装不上也传不了。

本技能是墨匠工坊的自研生产引擎（全库 37 个技能中唯一原创）：把 GitHub 上的 Agent Skills 体检、转换、打包成「本地能装＋平台能传」的双轨产出，许可准入与去毒审计双门禁拦截问题技能。

怎么用

  1. 从 GitHub 源目录下载技能包装入 AI 工具。
  2. 给出源技能的 GitHub 地址（或本地目录），技能自动完成：结构解析 → 可迁移性体检 → 字段补全 → 目录拉平 → 双轨打包。
  3. 拿到体检报告（风险逐项给等级与处置）和改动清单（改了什么、为什么改）后再决定是否安装上架。

真实边界（能做什么，不能做什么）

  • ✅ 做：Agent Skills 标准格式的定位/抓取、体检、转换、合规加固、打包全流程；许可 SPDX 自动识别；六类去毒审计（凭据泄露/提示词注入/危险执行/敏感读取/路径遍历/供应链）。
  • ❌ 不做：从零创作新技能；改写技能的领域方法论；非 Agent Skills 格式的提示词仓库。
