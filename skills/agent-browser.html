Agent 浏览器自动化

让 AI 替你开车浏览器：打开网页、填表、点击、截图、抓数、测 Web 应用，一条命令行全包。

能解决什么问题

  • 让 AI「打开这个网页填个表」它做不到——内置工具要么不驱动真浏览器，要么操作不可靠。
  • 重复性网页操作全靠手动：截图取数、表单提交、页面巡检，每天耗掉半小时。
  • Web 应用改版后想快速回归测试，没有趁手的自动化手段。

本技能是面向 AI 智能体的浏览器自动化命令行工具：通过 CDP 驱动 Chrome/Chromium，以无障碍树快照＋紧凑元素引用完成交互，比纯视觉方案更快更稳。除网页外还能驱动 Electron 桌面应用（VS Code、Slack、Figma、Notion 等）。

怎么用

  1. 从 GitHub 源目录下载本技能包，装入支持 Agent Skills 的 AI 工具。
  2. 环境就绪一条命令：安装 agent-browser（npm 全局包）后执行其 install 子命令配好浏览器。
  3. 之后直接用自然语言下指令：打开某站、填这个表单、点这个按钮、截图、把这页数据抓下来——技能负责翻译成自动化操作。

真实边界（能做什么，不能做什么）

  • ✅ 做：网页打开/填表/点击/截图/取数、Web 应用探索性测试与 QA、Electron 桌面应用自动化、Slack 等应用内操作。
  • ❌ 不做：从零创作新技能；需要强环境依赖方可执行的场景；绕过登录态或验证码的「破解式」抓取。
  • ⚠️ 注意：需要本机有 Chrome/Chromium 环境；目标网站的反爬与robots条款请自行遵守。
