能解决什么问题

  • 自然流量跌了不知道从哪查：索引？点击率？内容衰减？排查没有章法。
  • 网上 SEO 检查工具给的是通用建议，不看你自己站点的真实数据。
  • 想知道「哪些词离首页一步之遥」，不知道从哪挖速赢机会。

本技能用你站点自己的 Search Console＋GA4 数据做全面体检：索引健康、90 天环比表现基线、CTR 异常、衰减页面、擦边距离关键词、速赢清单——所有结论都来自真实后台数据，不是估算。

怎么用

  1. 从 GitHub 源目录下载本技能包装入 AI 工具。
  2. 配置免费的 Ryze MCP 连接器并授权你的 Search Console / GA4 账号（技能文档有接入指引）。
  3. 说「帮我做个 SEO 体检」，多个站点时会先让你确认用哪个，然后输出分项诊断与速赢清单。

真实边界（能做什么，不能做什么）

  • ✅ 做：索引状态与排除原因分析、90 天环比表现基线、CTR 异常页、衰减内容、擦边词机会、基于真实数据的速赢建议。
  • ❌ 不做：从零创作新技能；不接你自己的 GSC/GA4 就无从诊断——没有后台数据它宁可不干活也不编。
  • ⚠️ 注意：诊断结论是数据解读，落地改版仍需你的开发资源；Google 生态数据，百度后台不适用。
